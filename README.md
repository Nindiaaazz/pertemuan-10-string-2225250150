## Tugas
File `tugas/normalisasi_data_mahasiswa.py` digunakan untuk membersihkan nama, menormalisasi kode kelas, menghitung jumlah kata pada nama, dan membuat inisial nama.

## Cara Menjalankan
Jalankan program melalui terminal VS Code menggunakan perintah Python. Contoh:

`python latihan/01_dasar_string.py`

Untuk menjalankan tugas utama:

`python tugas/normalisasi_data_mahasiswa.py`

## Algoritma Tugas
1. Memasukkan nama dan kode kelas.
2. Menghapus spasi berlebih pada nama.
3. Mengubah nama menjadi format huruf kapital awal setiap kata.
4. Mengubah kode kelas menjadi huruf kapital dan mengganti pemisah spasi dengan tanda hubung.
5. Menghitung jumlah kata pada nama.
6. Mengambil huruf pertama dari setiap kata untuk membentuk inisial.
7. Menampilkan hasil normalisasi.
